协议笔记

从域名到页面

展开每一层，看看一次 HTTPS 访问（以 HTTP/1.1 为例）分别解决了什么问题。

DNS服务器在哪里？

客户端查询域名的 A 记录，得到 IPv4 地址。域名可能有多条地址记录。测试时，需要先分清 DNS 回答中的地址和浏览器实际连接的地址。

TCP双方怎样建立连接？

客户端发送 SYN，服务端回复 SYN、ACK，客户端再回 ACK。三次握手确认双方可以收发，并同步初始序列号。

TLS如何保护传输内容？

双方协商加密参数，客户端验证服务端证书。之后观察者仍能看到记录长度和时间，但通常看不到 HTTP 正文。

HTTP浏览器要的是哪份文件？

客户端发送 GET /，请求主页。服务器返回状态码、内容类型和 HTML。浏览器再把 HTML 显示成这张页面。
